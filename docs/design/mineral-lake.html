桌面几何

  • 标题栏 32px；主导航 184px；平台列表 168px。
  • 内容边距 24px；区块间距 20px；卡片间距 12px。
  • 平台行 34px；主导航项 38px；工具栏 34–36px。
  • 卡片内边距 16px；半径 10px；边框 1px。
  • 弹窗常规宽度 560–640px；内边距 24px；视口边界至少 16px。
  • 宽度 ≤900px 时主导航收为 68px；≤620px 平台列表改横向。

信息与交互

  • 标题 22px / 650；卡片身份 13px / 600；正文 12–13px；辅助信息 10–11px。
  • 账号才是主内容，不再把 16 个平台铺成大卡片。
  • 保留各平台 OAuth、Token、JSON、本机导入、签到、切换、刷新和编辑。
  • 卡片操作常驻，键盘聚焦可见；不以悬浮动画或发光表达状态。
  • 空状态至少 240px；列表、账号、弹窗使用同一套语义色。
  • 所有数据均为设计示例，不替换应用真实账号，不用于证明业务测试通过。
